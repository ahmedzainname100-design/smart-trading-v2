# Smart Trading

منصة عربية متجاوبة لمتابعة الأسواق وأدوات التحليل وإدارة المخاطر، مبنية باستخدام Python/Flask وHTML/CSS/JavaScript.

## ما الذي يتضمنه المشروع؟

- لوحة أسواق للذهب والفضة وأزواج الفوركس وBitcoin.
- تكامل اختياري مع Twelve Data لبيانات الأسعار والشموع من الخادم.
- شارت تفاعلي من TradingView مع مؤشرات فنية.
- قراءة فنية إرشادية للذهب عند توافر الشموع: EMA 20/50 وRSI 14 وMACD مبسط ومستويات نطاق حديثة.
- حاسبة فرق السعر بالنقاط، وإدارة المخاطر، والربح والخسارة، والعائد إلى المخاطرة.
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- مسار فحص صحة الخدمة `/health` وإعداد جاهز للنشر على Render.

## تشغيل محلي

يتطلب Python 3.11 أو أحدث.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:TWELVE_DATA_API_KEY="ضع_مفتاحك_هنا"
python app.py
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
export TWELVE_DATA_API_KEY="ضع_مفتاحك_هنا"
python app.py
```

ثم افتح `http://127.0.0.1:5000`.

## تفعيل بيانات السوق

1. أنشئ حسابًا في [Twelve Data](https://twelvedata.com/) واحصل على مفتاح API.
2. اضبط متغير البيئة `TWELVE_DATA_API_KEY` في بيئة التشغيل أو إعدادات الاستضافة. لا تضع المفتاح في ملفات JavaScript أو HTML ولا ترفعه إلى GitHub.
3. أعد تشغيل الخدمة.

الرموز المدعومة في هذه النسخة: `XAU/USD`, `XAG/USD`, `EUR/USD`, `GBP/USD`, `USD/JPY`, `BTC/USD`. توافر كل رمز وتواتر التحديث يعتمدان على صلاحيات الباقة ومزود البيانات. إذا لم يوجد المفتاح، تُظهر بطاقات الأسعار قيمًا توضيحية بعلامة واضحة، وليست أسعارًا حية. الشارت المضمن تابع لـTradingView وقد يختلف توقيت البيانات حسب السوق والمنطقة.

## النشر على Render

1. ارفع محتويات مجلد المشروع إلى مستودع GitHub جديد.
2. في Render اختر **New + → Blueprint** واربط المستودع الذي يحتوي `render.yaml`.
3. أضف قيمة `TWELVE_DATA_API_KEY` في Environment ضمن إعدادات الخدمة.
4. انشر الخدمة وافتح رابطها. فحص الصحة: `/health`.

يمكن أيضًا إنشاء Web Service يدويًا باستخدام:
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app --workers 2 --threads 4 --timeout 30`

## ملاحظات مهمة

- هذا مشروع معلوماتي؛ لا ينفذ صفقات ولا يتصل بحساب وسيط ولا يضمن الأرباح.
- الحسابات المالية تقديرية، وتحتاج قيمة العقد الصحيحة من مواصفات وسيطك.
- لا يتم نسخ ملفات أو كود داخلي من موقع آخر. الشارت المضمن يستخدم ويدجت TradingView الرسمي.
- لا توجد في المشروع حسابات مستخدمين أو كلمات مرور أو مفاتيح API مضمنة.

## أدوات التحليل الإضافية

تتضمن هذه النسخة حاسبات مستقلة لمستويات فيبوناتشي، وإسقاط جان 1×1 الحسابي، والدورات الزمنية، والنقاط المحورية الكلاسيكية، بالإضافة إلى حاسبات النقاط وإدارة المخاطر والربح/الخسارة والعائد إلى المخاطرة. أدوات الرسم التفاعلي داخل الشارت مقدمة من TradingView؛ توفرها وخصائصها تخضع لواجهة TradingView المضمنة.

## تفعيل الأسعار عبر Twelve Data على Render

في Render افتح الخدمة ثم **Settings → Environment → Add Environment Variable**، وأضف:
- Key: `TWELVE_DATA_API_KEY`
- Value: مفتاح API الذي تحصل عليه من حسابك لدى Twelve Data

احفظ التغييرات ثم أعد النشر. لا تضع المفتاح داخل ملفات GitHub أو داخل JavaScript. توفر الأسعار الفورية وتواترها يعتمدان على الرمز وباقة مزود البيانات. عند غياب المفتاح، تعرض المنصة قيماً توضيحية معلّمة بوضوح ولا ينبغي التعامل معها كأسعار حقيقية.
